NEXUSASSET CLOUD - SYSTEM ARCHITECTURE DEEP ANALYSIS
1. OVERVIEW
Employs modern, scalable enterprise architecture based on Domain-Driven Design (DDD) and Clean Architecture.

2. CLEAN ARCHITECTURE LAYER ENFORCEMENT
- Domain Layer: Pure business logic. NO dependencies on Django, DRF, ORM, or HTTP.
- Application Layer: Orchestrates use cases. Depends ONLY on Domain and abstract ports.
- Infrastructure Layer: Implements interfaces (Django ORM, external API clients).
- Interfaces Layer: DRF Views, Serializers, and URL routing.

3. BOUNDED CONTEXTS
- nxa_core, nxa_accounts, nxa_tenants, nxa_assets, nxa_lansweeper, nxa_billing, nxa_notifications, nxa_audit.

4. MULTI-TENANCY ARCHITECTURE
Logical multi-tenancy (Shared Database, Shared Schema). Every tenant-owned table includes a `tenant_id`. Defense-in-depth via PostgreSQL Row-Level Security (RLS).

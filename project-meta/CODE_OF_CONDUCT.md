# Code of Conduct

NexusAsset Cloud contributors and maintainers are expected to communicate professionally, respectfully, and constructively.

## Expected Behavior
- Focus feedback on code, architecture, documentation, and user impact.
- Assume good intent and ask clarifying questions.
- Protect confidential, security-sensitive, and tenant data.

## Unacceptable Behavior
- Harassment, discrimination, threats, or abusive conduct.
- Sharing secrets, credentials, or cross-tenant data.
- Bypassing required security and quality controls.

## Reporting
Report concerns to `docs@nexusasset.cloud` or `security@nexusasset.cloud` for security-related issues.

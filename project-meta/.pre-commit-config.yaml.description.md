# NexusAsset Cloud — Pre-Commit Hooks Description

**Original artifact:** `.pre-commit-config.yaml` (converted to English description; original file removed per approved scope 1).

## Purpose
Defines automated checks run before commits.

## Inputs / Parameters
Developer commits and staged files.

## Outputs / Behavior
Pass/fail hook results; commits blocked on configured failures.

## Detailed Description
Hooks should include formatting/linting (ruff/black/eslint/prettier as adopted), secret scanning (gitleaks), file hygiene, YAML/JSON validation, and optional architecture/commit-message checks, aligned with CI gates.

## NexusAsset Cloud Constraints
- Secret scanning must block credential commits.
- Pin/review hook versions.

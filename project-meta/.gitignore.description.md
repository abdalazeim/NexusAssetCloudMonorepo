# NexusAsset Cloud — Git Ignore Policy Description

**Original artifact:** `.gitignore` (converted to English description; original file removed per approved scope 1).

## Purpose
Defines repository paths and file patterns that must not be tracked by version control.

## Inputs / Parameters
Git status/add operations.

## Outputs / Behavior
Untracked/generated/sensitive local files are excluded from commits.

## Detailed Description
The ignore policy covers OS/editor artifacts, local environment files (including `.env` variants except approved templates), dependency caches/build outputs for Python/Node/Next.js/Android, test/coverage reports, logs, temporary files, IDE metadata, local infrastructure state, and generated artifacts where appropriate. It must allow approved templates while blocking real secret files.

## NexusAsset Cloud Constraints
- Never allow real `NXA_*` secrets, tokens, or private keys to be committed.

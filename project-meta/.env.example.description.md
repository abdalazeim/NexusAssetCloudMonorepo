# NexusAsset Cloud — Environment Variable Template Description

**Original artifact:** `.env.example` (converted to English description; executable/config source removed per approved scope 1).

## Purpose
Provides a non-secret `NXA_*` environment variable template.

## Inputs / Parameters
Operators/developers configuring environments.

## Outputs / Behavior
Reference list of expected `NXA_*` variables.

## Detailed Description
Includes environment/debug flags, secret key placeholder, allowed hosts, PostgreSQL and Redis URLs, JWT TTL settings, Lansweeper API/auth/token placeholders, Traefik dashboard host, public web/API URLs, logging level, and OpenTelemetry OTLP endpoint. Real values come from uncommitted env files or approved secret managers.

## NexusAsset Cloud Constraints
- Never commit real credentials/tokens.
- Manage `NXA_SECRET_KEY`, `NXA_LANSWEEPER_TOKEN`, DB passwords, and signing secrets securely.

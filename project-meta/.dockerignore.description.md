# NexusAsset Cloud — Docker Build Ignore Policy Description

**Original artifact:** `.dockerignore` (converted to English description; original file removed per approved scope 1).

## Purpose
Defines files excluded from Docker build contexts.

## Inputs / Parameters
Docker build context collection.

## Outputs / Behavior
Smaller, safer build contexts.

## Detailed Description
Excludes VCS metadata, unnecessary drafts, node modules/caches, Python caches/virtual environments, local env files, test artifacts, IDE files, logs, and build outputs not required by target Dockerfile contexts.

## NexusAsset Cloud Constraints
- Exclude real secret files.
- Keep required manifests/source paths available to each Dockerfile.

# NexusAsset Cloud — Definition of Done

## Status
Target governance baseline.

## Minimum DoD (when applicable)
- Acceptance criteria met and status-labeled.
- Docs/contracts updated (OpenAPI, ADRs, runbooks as needed).
- Tests added/updated with evidence.
- Tenant/security impact reviewed.
- Quality/security gates pass or exceptions are approved and documented.
- Rollout/rollback considerations captured for risky changes.

## 2. Domain-Specific Terminology

### 2.1 NexusAsset Core Concepts

| Term | Definition | Context |
|------|------------|---------|
| **Asset** | Any IT resource (hardware, software, virtual, cloud) tracked in the system | ITAM |
| **Asset Category** | Classification grouping (Hardware, Software, Virtual, Network, Peripheral) | ITAM |
| **Asset Status** | Lifecycle state (Active, Inactive, Maintenance, Retired, Lost) | ITAM |
| **Asset Type** | Specific type within category (Workstation, Server, Mobile, etc.) | ITAM |
| **Custom Field** | Tenant-defined extensible attribute on assets | ITAM |
| **Tenant** | Isolated customer environment with dedicated schema and data | Multi-tenancy |
| **Tenant Tier** | Service level (Starter, Professional, Enterprise) | Billing |
| **Schema** | PostgreSQL namespace isolating tenant data | Multi-tenancy |
| **Reconciliation** | Process of merging discovered data with master records | Lansweeper Sync |
| **Field Ownership** | Rules defining which system (Lansweeper vs NexusAsset) owns each field | Lansweeper Sync |
| **Golden Record** | Authoritative merged asset record after reconciliation | Lansweeper Sync |
| **Sync Job** | Scheduled or triggered data synchronization from external source | Lansweeper Sync |
| **Vulnerability** | Known security weakness in software/hardware (CVE-based) | Security |
| **Risk Score** | Calculated severity metric based on vulnerabilities and context | Security |
| **License Type** | Licensing model (Per Device, Per User, Per Core, Subscription, etc.) | SAM |
| **Entitlement** | Purchased license quantity and terms | SAM |
| **Compliance** | Adherence to license terms and regulations | SAM |
| **Software Product** | Normalized software title from discovery sources | SAM |
| **Notification Template** | Reusable message template for alerts and communications | Notifications |
| **Notification Channel** | Delivery mechanism (Email, Slack, Webhook, PagerDuty, SMS) | Notifications |
| **Audit Log** | Immutable record of security-relevant events | Audit |
| **Processing Activity** | GDPR Art. 30 record of data processing operations | GDPR |
